# Olin QEA-1 Flashcards
This is an Anki flashcard deck for the Olin QEA-1 course (at least the 2025 course). Anki is a free, open source flashcard software that can be downloaded [here](https://apps.ankiweb.net/)


These cards were made with information from the curriculum materials and external research. Credit to [GeeksforGeeks](https://www.geeksforgeeks.org/) for aiding in some of the definitions and explanations. Enjoy!
